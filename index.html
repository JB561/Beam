How a beam works

    Open Send on one deviceYou get a 6-character code and a QR.

Bluetooth can't carry files between two browsers — the browser sandbox forbids it. BEAM uses the direct peer-to-peer channel instead, which is 50–200× faster. For literally radio-only transfers with no network of any kind, see the bundled Android Wi-Fi Direct build in /android.
